# Postgraduate Diploma in Data Analytics- Programming for Data Analytics
# Formative Assignment Part 1- Multiple Linear Regression

This repository has my formative assessment part 1 for Programming in Data Analytics as a student pursuing a Postgraduate Diploma in Data Analytics. 
The analysis uses a medical insurance dataset found on Kaggle by Miri Choi to investigate how different variables including age, sex, smoking status, number of children, BMI and geographic region can be used to predict the medical charges for different individuals
